How it works

The system combines environmental sensor readings with a hybrid rule-based and ML scoring approach. This helps flag sudden changes in slope conditions before a failure event becomes severe.

The model supports early-warning planning but should not replace official alerts from disaster management authorities.

Limitations

This dashboard is an academic prototype and is designed for research, demonstration, and decision support. Real deployments should use calibrated field instruments, site-specific datasets, and operational emergency protocols.
